Is it safe?

It’s open source

Every line of Lingo is on GitHub. Each release is built and tested by GitHub Actions straight from that code, so the app you download is the code you can read.

What it can access — and why
  • Accessibility — so the letter you press together with fn switches the layout instead of being typed. Lingo only reacts to fn + your chosen letters; it doesn’t record or store anything you type.

macOS asks you first; Lingo is already in the list, you just flip the switch. You can turn it off any time in System Settings → Privacy & Security.

Does it send my data anywhere?

No. Lingo never sends what you type anywhere. Its only network request is a daily check on GitHub for a new version (you can turn it off in Settings). No analytics, no accounts, no tracking.

Why doesn’t macOS say “verified developer”?

Apple charges $99 a year for that badge. Lingo is a free side project, so it’s signed locally instead. The Terminal command installs it without any warning. With the DMG, macOS asks once — click Open Anyway in System Settings → Privacy & Security.

How do I check the download?

Compare the SHA-256 of the file with the one published on the release page:

shasum -a 256 ~/Downloads/Lingo.dmg
see the release page

How do I uninstall it?

Quit Lingo from its menu and drag it from Applications to the Trash — or run
curl -fsSL https://getlingo.dev/install.sh | bash -s -- uninstall

Tip: fn on its own switches layouts too

Set System Settings → Keyboard → “Press 🌐 key to” → Do Nothing.
